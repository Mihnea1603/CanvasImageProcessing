Image Processing

This image processing application is responsible for retrieving and manipulating images from the NASA API. It is structured into several functions that provide specific functionalities:

The mirrorImage(imgData, slice) function performs a horizontal mirroring of a portion of the image, dividing it into four execution slices. This is done by swapping pixels between the left and right sides.

The laplacian(imgData, slice) function applies the Laplacian operator to a portion of the image, highlighting edges and rapid changes in intensity. The result is an image with enhanced contours and areas where intensity varies sharply.

The processImage(modifyImage, imgData) function coordinates the image processing, disabling the buttons during the operation and updating the canvas after each step.

The getImage() function retrieves images from the NASA API, displaying a random image. It returns an ImageData object for further use in the processing pipeline.

The main() function coordinates the main functions of the application, allowing the image to be updated and various processing operations to be performed.
